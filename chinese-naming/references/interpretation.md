# 吉凶斷語解讀指南（interpretation）

本 skill 的三類判斷資料：81 數理吉凶、三才配置吉凶、漢字五行。下面是給 LLM 使用者的
「輸出報告框架」——不是硬性模板，而是確保任何分析報告都涵蓋關鍵要素的檢查清單。

## 報告結構建議

1. **基本資料**：姓名、單姓/複姓、各字康熙筆畫（若與現代筆畫不同，特別標出，例：陳 16 畫）。
2. **五格數值表**：天/人/地/總/外 五格各列 數值、五行、81 數理吉凶、特質。
3. **三才**：config（五行組合）、吉凶、斷語摘要。
4. **綜合判斷**：不要只報單格。常用規則：
   - 人格、地格、總格、外格是「可用格」；天格由姓氏先天決定，不因改名變動。
   - 三才看五行生剋：相生（木火土金水循環）多吉；相剋要看方向與配置。
   - 有一格凶不代表全盤凶；若人/地/總 任一為大凶，須明確提示「此名需注意」。
   - 斷語文本來自資料表，引用時保留原意，可加「依傳統姓名學說法」前綴。
5. **參考聲明**：姓名學為傳統文化參考，不具科學預測效力，重要決定（改名、商業命名）宜多方諮詢。

## 三才吉凶等級

sancai.json 每配置含 result（等級）與 evaluate（斷語全文）：

| 等級 | 判讀 |
|---|---|
| 大吉 / 吉 / 中吉 | 上佳配置 |
| 吉多于凶 / 吉凶参半 | 中性偏吉，留意短板 |
| 凶多于吉 / 凶多吉少 | 偏凶，慎用 |
| 大凶 / 凶 | 避用 |

sancai.txt 缺 4 個配置（土火金、木土水、火火木、金金火），由 PiPiName wuge.py 的
WUXING_GOODS/GENERALS/BADS 分類補入吉凶等級，斷語標註「此配置 sancai.txt 無斷語」。

## 取名報告範例（供 LLM 產出參考）

```
## 分析：王小明（單姓）
- 康熙筆畫：王=4 小=3 明=8
- 五格：
  天格 5(土) 大吉　人格 7(金) 大吉　地格 11(木) 大吉
  總格 15(土) 大吉　外格 9(水) 凶
- 三才：土金木 → 凶多于吉
  斷語：勞心不絕，基礎不穩，須防意外之遭難…（本名資料表原文）
- 綜合：人/地/總三格皆大吉，唯外格與三才偏弱；性格主運（人格 7）含剛情運，
  領導力與決斷強，但三才土金木為木剋土之象，基礎運需留意。若以原名為例，
  貴在總格 15 財富運；若要改運，可朝水木或金水之三才組合調整。
- 聲明：以上為傳統姓名學參考，非科學預測。
```

## 對外說明準則

- 資料庫範圍有限（康熙 50,927 字、五行 7,013 字、三才 125 配置、81 數理全表）；
  查不到筆畫的字會明確報錯，回覆時如遇「未知」五行或「未知配置」照實說明。
- 避免把姓名學講成宿命論；強調是文化傳統與參考框架。
- 不承諾改名/命名能改變命運；成效取決於個人努力。
