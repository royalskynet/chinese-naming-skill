# 五格計算規則（wuge-rules）

本 skill 的五格計算規則與 GoodGoodName（JakLiao/GoodGoodName）、PiPiName（NanBox/PiPiName）
一致，筆畫一律採**康熙字典筆畫**。

## 名詞

- **天格**：姓氏先天格，主祖輩、長輩、先天運。
- **人格**：主一生運勢、個性，又稱「主運」。
- **地格**：主前半生、子女、婚姻，又稱「前運」。
- **總格**：主後半生、一生總運，又稱「後運」。
- **外格**：主社交、外在人際，又稱「副運」。

## 康熙筆畫 vs 現代筆畫

康熙字典計筆畫時，偏旁以原部首計：

| 偏旁 | 現代筆畫 | 康熙計法 |
|---|---|---|
| 氵（三點水） | 3 | 水 4 畫 |
| 扌（提手旁） | 3 | 手 4 畫 |
| 艹（草字頭） | 3 | 艸 6 畫 |
| 辶（走之旁） | 3 | 辵 7 畫 |
| 阝（左耳/右耳） | 依位置 | 阜/邑 8/7 畫 |
| 礻（示字旁） | 4 | 示 5 畫 |
| 衤（衣字旁） | 5 | 衣 6 畫 |
| 犭（反犬旁） | 3 | 犬 4 畫 |
| 忄（豎心旁） | 3 | 心 4 畫 |

因此 `陳`＝16、`黃`＝12、`謝`＝17 等姓氏的筆畫與簡體/現代寫法常不同。
assets/strokes.json 已含全部康熙筆畫（50,927 字），腳本直接查表。

## 五格公式

### 單姓雙名（最常見，3 字名）

```
天格 = 姓筆畫 + 1
人格 = 姓筆畫 + 名第1字筆畫
地格 = 名第1字筆畫 + 名第2字筆畫
總格 = 姓筆畫 + 名兩字筆畫和
外格 = 總格 - 人格 + 1
```

例：王小明（王=4 小=3 明=8）
```
天格 = 4+1   = 5
人格 = 4+3   = 7
地格 = 3+8   = 11
總格 = 4+3+8 = 15
外格 = 15-7+1 = 9
```

### 複姓雙名（4 字名，如 歐陽娜娜）

```
天格 = 複姓兩字筆畫和
人格 = 複姓第2字筆畫 + 名第1字筆畫
地格 = 名第1字筆畫 + 名第2字筆畫
總格 = 複姓兩字 + 名兩字筆畫和
外格 = 總格 - 人格 + 1
```

例：歐陽娜娜（歐=15 陽=17 娜=10）
```
天格 = 15+17   = 32
人格 = 17+10   = 27
地格 = 10+10   = 20
總格 = 15+17+10+10 = 52
外格 = 52-27+1 = 26
```

### 單名（2 字名，如 王力）

```
天格 = 姓筆畫 + 1
人格 = 姓筆畫 + 名筆畫
地格 = 名筆畫 + 1
總格 = 姓筆畫 + 名筆畫
外格 = 2（固定，標準五格規則）
```

例：王力（王=4 力=2）
```
天格 = 4+1     = 5
人格 = 4+2     = 6
地格 = 2+1     = 3
總格 = 4+2     = 6
外格 = 2
```

### 複姓單名（3 字名，如 歐陽修）

```
天格 = 複姓兩字筆畫和
人格 = 複姓第2字筆畫 + 名筆畫
地格 = 名筆畫 + 1
總格 = 複姓兩字 + 名筆畫
外格 = 2（固定，標準五格規則）
```

例：歐陽修（歐=15 陽=17 修=10）
```
天格 = 15+17 = 32
人格 = 17+10 = 27
地格 = 10+1  = 11
總格 = 15+17+10 = 42
外格 = 2
```

## 五行判定（由數值尾數）

| 尾數 | 五行 |
|---|---|
| 1、2 | 木 |
| 3、4 | 火 |
| 5、6 | 土 |
| 7、8 | 金 |
| 9、0 | 水 |

三才配置 = 天格五行 + 人格五行 + 地格五行（例：土金木）。

## 81 數理查表

五格數值 > 81 時以 81 為週期循環取餘（1..81 對應），
`shuli81.json` 以 1–81 為 key，含 grade（大吉/中吉/凶/平）與 traits（特質標籤）。
